## 首轮真机反馈与修复

- 模型下载报 `ENOENT`：下载/解压前创建 `filesDir/models`
- 下载报 `Software caused connection abort`：增加 3 次断点重试，并提供“从本地 ZIP 导入模型”
- 解压报“缺少模型根目录”：区分 ZIP 根目录 `vosk-model-small-cn-0.22` 与安装 ID `vosk-small-cn-0.22`
- 只弹通知权限、通话报 `Cannot create AudioRecord`：进入通话页先申请 `RECORD_AUDIO`，授权后才初始化；拒绝时提供重新授权/系统设置入口
- 已安装模型仍提示重复安装：自动扫描安装 ID 与官方根目录两种布局，完整 ZIP 缓存时提示继续安装

## 真机测试清单

### 1. 权限与初始化

- [ ] 首次进入通话页弹出麦克风权限；拒绝后显示可读提示，不进入死循环
- [ ] Android 13+ 弹出通知权限；拒绝后通话仍可进行，通知不显示但不崩溃
- [ ] Vosk 模型未下载时进入通话，显示准备状态；下载失败可重试，不产生半解压目录
- [ ] 系统 TTS 未安装中文语音时给出错误，不静默卡在 Speaking

### 2. 基础语音链路

- [ ] 说一句中文，partial 实时出现，端点后进入 Thinking
- [ ] 收到回复后按句播报，句间无明显截断；播报结束自动回到 Listening
- [ ] 连续 5 轮对话状态不串台，旧 TTS Done 不误触发新状态
- [ ] 键盘输入可替代一轮语音；发送后进入 Thinking/Speaking
- [ ] 停止生成可取消当前请求并回到 Listening
- [ ] 打断播报后 300ms 内停止出声并回到 Listening

### 3. 回声与音频路由

- [ ] 免提外放时无明显自激/回声；AEC 生效
- [ ] 听筒/免提切换立即生效，UI 状态与实际路由一致
- [ ] 插入耳机/蓝牙耳机时录音与播报路由正确
- [ ] 挂断后系统媒体音量、音频模式、扬声器状态恢复；其他应用可正常出声

### 4. 生命周期

- [ ] 通话中锁屏，录音与前台服务继续；通知可见
- [ ] 切后台 5 分钟不被杀；返回后状态一致
- [ ] 通话中旋转屏幕/折叠屏形态切换不重复启动采集
- [ ] 贴近传感器时屏幕调暗/熄屏，离开恢复；无接近传感器设备不崩溃
- [ ] 挂断后前台服务、WakeLock、AudioRecord、Vosk、TTS 全部释放

### 5. 稳定性与耗电

- [ ] 连续通话 1 小时无 OOM/ANR；记录电量下降、CPU、温度
- [ ] 弱网/断网时 ChatRepository 失败可读，不自动死循环
- [ ] API Key 缺失/无效时给出错误，不进入 Speaking
- [ ] 通话记录在会话列表可见，标题为“语音通话 MM-dd HH:mm”；聊天默认参数未被改写

### 6. 兼容矩阵

至少覆盖：Android 11、12、13、14、15、16 各一台；直板/折叠/平板各一台；有/无接近传感器、有/无麦克风设备。
