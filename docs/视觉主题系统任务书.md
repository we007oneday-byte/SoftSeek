# 任务：SOFTSEEK 十套视觉主题系统（UI 风格约束）

实现 Jetpack Compose 十套视觉主题。本文只约束**视觉呈现与交互表现**，
Kotlin 架构与具体 API 写法由实现方自行决定，只需保证：
- 所有颜色、圆角、间距、边框、阴影都来自 `VisualStyleSpec`，不硬写字面量；
- 低端设备（isLowEndDevice = true）视觉降级符合各主题规定；
- Background 一律 Canvas + 渐变 + Path，禁止图片资源；
- 代码可编译，依赖 material3 / datastore-preferences / compose-ui / compose-animation。

---

## 一、硬性视觉规则

1. **错误色固定**：每套 ColorScheme 的 `error` 必须是 `Color(0xFFE53935)`，
   不允许被主题调色覆盖；`onError` 为白。
2. **枚举顺序固定**：
   `Minimal(默认), Cloud, Pudding, Mono, Taiji, Hacker, LineArt, Candy, Neon, PaperInk`
3. **ColorScheme 完整度**：每套主题必须给完整色板（至少覆盖 primary / onPrimary /
   secondary / tertiary / background / onBackground / surface / onSurface /
   surfaceVariant / onSurfaceVariant / outline / error / onError），
   不允许只给 3–4 个颜色。
4. **尺寸**：所有圆角 / 间距 / 边框 / elevation 全部来自 `VisualStyleSpec`，
   通用组件内不出现硬写 dp 字面量。
5. **低端设备视觉降级**：`isLowEndDevice = true` 时——关闭 Canvas 动画、
   关闭毛玻璃模糊、关闭辉光，仅保留静态色块与静态线条布局。
6. **可复用组件**（读取当前主题 spec）：
   `StyleAwareCard(backdropBlur: Boolean)`、`StyleAwareBubble(isMine: Boolean)`、
   `StyleAwareButton`（点击带 spring 弹簧按压缩放）、`StyleAwareSettingItem`。
7. **通话页两个独立 UI 动画框架**（不接业务）：
   - `CallSubtitleArea(textList, highlightIndex, modifier)`：逐行淡入 + 上浮入场，
     支持指定行高亮。
   - `VoiceVisualizerCanvas(volume, style, modifier, isLowEndDevice)`，
     枚举 `VoiceAnimationStyle` 共 10 种：
     波形 / 脉冲 / 环形 / 粒子 / 频谱 / 打字机 / 光晕 / 扫描线 / 弹性字 / 涟漪。
     低端设备降低采样点/元素数量，画面保持静帧或最小动效。
8. **主题切换动画**：主题切换时关键背景/表面/主色/文字色平滑过渡
   （用 `animateColorAsState`），不要求 ColorScheme 全字段逐个动画。

## 二、视觉语义澄清（只保证效果对，不锁 API）

这三条不改变架构，只保证**你看到的效果和主题描述一致**：

- **backdropBlur**：视觉目标 = 卡片**背后的内容**变模糊（磨砂玻璃）。
  禁止用只模糊组件自身内容的 `Modifier.blur()`——那会让卡片里的文字变糊而不是背景。
- **辉光（Hacker / Neon）**：视觉目标 = 边框**四周均匀扩散的光晕**。
  禁止用 `drawShadow()`——那是下方投影，不是外发光。
- **颜色过渡范围**：只对 `background / surface / primary / onBackground / onSurface`
  平滑过渡，其余字段直接切换（避免 30+ 字段逐个动画造成切换卡顿）。

## 三、扩展性约定（为后续新增风格准备）

> 以下 4 条不涉及 Kotlin 架构，只保证"以后加第 11、12 套风格时不会静默翻车"。

1. **分发穷举**：任何按 `VisualStyle` 分发的 `when`（`getSpec`、`CurrentStyleBackground`
   等），**禁止写 `else` 分支**，只写已声明的枚举成员分支。
   新增风格时让编译器强制提醒你补齐所有分发点，而不是静默走默认。
2. **反序列化兜底**：DataStore 读取时用
   `runCatching { VisualStyle.valueOf(name) }.getOrDefault(VisualStyle.Minimal)`，
   避免删除 / 重命名风格后，老数据里的旧枚举名导致启动崩溃。
3. **一主题一文件**：每套主题独立文件（如 `ThemeCloud.kt` / `ThemeNeon.kt`），
   文件内含该主题的 `buildLightScheme / buildDarkScheme / XxxBackground`。
   禁止把所有主题塞进一个文件——加风格时单文件会迅速膨胀。
4. **预览遍历**：提供一个 `@Preview` 包裹器，循环 `VisualStyle.entries` 渲染缩略，
   新增风格后无需改预览参数即可看到效果。

## 四、十套主题视觉参数

> 通用：`error = 0xFFE53935`，以下不再重复。

### 1. Minimal 极简【系统默认】
- forceDarkMode = false
- cardRadius 12dp / bubbleRadius 10dp / spacing 12dp / border 0.5dp / elevation 0dp
- 浅色：背景 #F7F7F7，中性灰阶，低饱和强调色
- 深色：深灰底
- Background：纯色，无装饰

### 2. Cloud 云朵
- forceDarkMode = false
- cardRadius 28dp / bubbleRadius 24dp / spacing 16dp / border 1dp / elevation 2dp
- 浅色：背景 #F8FCFF，表面 #CFE2F3，主色 #7FE0FF
- 深色：深灰蓝底，半透明淡云灰表面
- Background：线性渐变 + 圆组合云朵横向漂浮（Animatable 驱动）
- 低端：关云朵动画，仅保留渐变
- Card：backdropBlur 打开时呈半透明磨砂；关闭时纯色表面

### 3. Pudding 布丁
- forceDarkMode = false
- cardRadius 32dp / bubbleRadius 28dp / spacing 14dp / border 1dp / elevation 4dp
- 浅色：奶黄 #FFF4D9、蜜桃 #FFE6EB、奶白
- 深色：深焦糖底、浅奶油表面
- Background：径向渐变 + 半透明圆形奶泡（可动画）
- 低端：关奶泡动画
- Card：多层柔光高光，模拟果冻质感；Button：spring(dampingRatio = 0.6f) 挤压回弹

### 4. Mono 黑白
- forceDarkMode = false
- cardRadius 8dp / bubbleRadius 8dp / spacing 12dp / border 1dp / elevation 0dp
- 浅色：纸白、多级灰度、墨黑；深色：纯黑底、浅灰字
- Background：纯色无装饰
- 全部无 elevation，层级靠 Divider 分割线
- 图标描边（outline）风格

### 5. Taiji 太极
- forceDarkMode = false
- cardRadius 36dp / bubbleRadius 36dp / spacing 18dp / border 1dp / elevation 1dp
- 浅色：宣纸白、墨黑、极淡赭石；深色：深墨底、灰白字
- Background：Canvas 低 alpha 阴阳鱼 Path 暗纹 + 极低强度宣纸噪点
- 低端：关噪点
- 边框呈现渐变水墨晕染感
- 阴阳鱼仅作暗纹，不抢内容焦点

### 6. Hacker 黑客【强制暗色】
- forceDarkMode = true
- cardRadius 2dp / bubbleRadius 4dp / spacing 10dp / border 1dp / elevation 2dp
- 仅暗色：底 #0C0C0C、荧光绿 #39FF14、暗灰
- Background：半透明横向扫描线（可动画）
- 低端：关扫描线
- Card / Button 边框呈现柔和荧光外发光（辉光）；低端移除辉光
- 卡片近乎直角；等宽字体

### 7. LineArt 线条
- forceDarkMode = false
- cardRadius 16dp / bubbleRadius 14dp / spacing 14dp / border 1dp / elevation 0dp
- 浅色：白底深灰描边；深色：黑底浅灰描边
- Background：纯色无装饰
- **Card / Button / Bubble 只有 stroke 描边，内部填充透明**
- Divider 用虚线

### 8. Candy 糖果
- forceDarkMode = false
- cardRadius 26dp / bubbleRadius 22dp / spacing 15dp / border 1dp / elevation 3dp
- 浅色：低饱和糖果粉 / 柠檬黄 / 薄荷绿渐变；深色：暗紫底、半透明彩卡
- Background：柔和渐变 + 低 alpha 漂浮气泡（可动画）
- 低端：关气泡
- Card：默认开启 backdropBlur 磨砂

### 9. Neon 霓虹【强制暗色】
- forceDarkMode = true
- cardRadius 18dp / bubbleRadius 16dp / spacing 13dp / border 1dp / elevation 3dp
- 仅暗色：深紫蓝底、青色霓虹、淡粉霓虹
- Background：静态半透明细网格（不做网格动画）
- Card / Button 边框呈现柔和霓虹外发光；低端移除辉光；禁止过曝强光

### 10. PaperInk 纸墨
- forceDarkMode = false
- cardRadius 20dp / bubbleRadius 18dp / spacing 20dp / border 1dp / elevation 1dp
- 浅色：宣纸白、墨黑；深色：墨黑纸张底、灰白字
- Background：极低强度纸张噪点
- 低端：关噪点
- 页面大外边距，模拟文档阅读留白
- error 朱红仅用于 error，禁止作普通装饰色
